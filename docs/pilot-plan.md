# План пилотной репетиции

Текущее состояние: чистая установка на PostgreSQL и основной цикл через API проверены на изолированном стенде. Реальный пилот **не начинался**. Фактические результаты находятся в `docs/qa-report.md`.

## Перед обсуждением пилота

1. Проверить P1 из `docs/backlog.md`, особенно серверные черновики и отказ чтения после commit; повторить восстановление на инфраструктуре заказчика.
2. Получить решение ответственного вуза о составе данных, сроках хранения, методичке, официальных оценках вне системы и поддержке. Не считать редактируемый шаблон официальным.
3. Провести на отдельном стенде сценарий с одной согласившейся группой, преподавателем и лабораторной; сначала без реальных работ и аккаунтов. Проверить браузеры, смартфон и планшет в обеих ориентациях.
4. Измерять фактическое время подачи, до первого отзыва, число пересдач и обязательных распечаток. Пока эти показатели **не измерены**; экономия времени не заявляется.
5. Отдельно проверить загрузку PDF/DOCX и документ из формы, затем сверить версии, квитанции, замечания и восстановление из копии.

## STOP / GO

STOP: чужой доступ, потеря/подмена версии, ложная квитанция или согласование, невозможность вернуть замечания, утечка файла, непроверенное восстановление. Локальное восстановление проверено; на сервере заказчика его нужно повторить. GO для пилота потребует закрытия блокеров, проверки стенда и решения ответственного.
