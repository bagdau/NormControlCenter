# Роли и права

| Ресурс | Студент | Преподаватель | Администратор |
|---|---|---|---|
| Задание | Только назначенной группы | Только собственное при активном назначении | Управление структурой, без содержимого работ |
| Черновик/сдача | Только собственная | Только своего задания | Нет доступа |
| Файл версии | Только собственный | Только своего задания | Нет доступа |
| Замечание | Читать опубликованное, отвечать при пересдаче | Создавать и публиковать к актуальной версии своего задания | Нет доступа |
| Согласование | Читать итог | Установить после закрытия обязательных пунктов | Нет доступа |

Проверка выполняется на сервере при каждом запросе. Отзыв назначения прекращает доступ на следующем запросе, включая старую вкладку. Администратор не может читать или скачивать работу. Контракт пока не покрывает полноценно защищённые cookie и CSRF; см. backlog.
