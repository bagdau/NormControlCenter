# DESIGN.md — Визуальная система «НормКонтрольЦентр»

Интерфейс построен вокруг ясной иерархии, спокойных нейтральных поверхностей и точных цветовых сигналов. Цвет и движение помогают находить действия, но не заменяют подписи и состояния. Исходные архивы использовались как материалы для изучения структуры экранов; рабочий интерфейс реализован на React и TypeScript.

## Цветовая палитра
- **Основной фон (`background` / `surface`)**: `#f5f5f7`
- **Поверхности карточек (`surface-container-lowest`)**: `#ffffff`
- **Второстепенные панели (`surface-container-low` / `surface-container`)**: `#f6f6f8` / `#f0f0f3`
- **Основной акцент (`primary` / `primary-fixed`)**: `#174ea6` / `#e8f0ff`
- **Успешная запись (`secondary` / `secondary-container`)**: `#16745e` / `#e2f4ec`
- **Ошибка (`error` / `error-container`)**: `#b42334` / `#fff0f0`
- **Повторная проверка / версия (`tertiary` / `tertiary-fixed`)**: `#6945a3` / `#eee8f8`
- **Основной текст (`on-surface` / `on-surface-variant`)**: `#1d1d1f` / `#5e6068`

## Типографика и символы
- **Заголовки и интерфейс**: системный шрифт платформы с запасным `Inter`; заголовки 600, основной текст 400–600.
- **Коды, таймеры, хэши, страницы**: `SFMono-Regular` / `Consolas` + табличные цифры.
- **Поддержка казахского языка**: полная поддержка `Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, І` в интерфейсе и встроенном шрифте `DejaVuSerif` при экспорте PDF.

## Адаптивные брейкпоинты и ориентации
- `320px` / `390px`: одноколоночная вёрстка, нижняя панель навигации с дополнительным меню для оставшихся разделов, доступность всех основных действий.
- `768×1024` (планшет портрет): документ сверху/на весь экран, выдвижная панель замечаний.
- `1024×768` (планшет альбом): документ и панель замечаний рядом в две колонки.
- `1440px` (десктоп): левая панель (`w-72`) и рабочая область с шириной содержимого до `7xl`.

## Взаимодействие и доступность
- Зоны нажатия основных контролов имеют высоту не менее 44 пикселей; текущий раздел помечается `aria-current`.
- Ссылка «Перейти к содержанию», видимый фокус и режим `prefers-reduced-motion` поддерживают навигацию с клавиатуры и без анимаций.
- Квитанцию на узком экране можно закрыть свайпом вниз за верхнюю область. Кнопка закрытия и клавиша Escape доступны всегда. Свайпы не выполняют сдачу, согласование и другие действия, меняющие данные.
- Предупреждения о сети остаются текстовыми; статус записи подтверждается серверной квитанцией.
