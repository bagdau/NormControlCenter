# DESIGN.md — Визуальная система «НормКонтрольЦентр»

Источник: макеты Google Stitch (`design/*.html`), адаптированные под спокойный академический интерфейс с высокой читаемостью и чёткой семантикой статусов.

## Цветовая палитра (Light Academic Surface)
- **Основной фон (`background` / `surface`)**: `#f8f9ff`
- **Поверхности карточек (`surface-container-lowest`)**: `#ffffff`
- **Второстепенные панели (`surface-container-low` / `surface-container`)**: `#eff4ff` / `#e5eeff`
- **Основной акцент (`primary` / `primary-container`)**: `#00236f` / `#1e3a8a`
- **Вторичный акцент (`secondary` / `secondary-container`)**: `#006a61` / `#86f2e4`
- **Предупреждение / возврат / просрочка (`error` / `error-container`)**: `#ba1a1a` / `#ffdad6`
- **Повторная проверка / версия (`tertiary` / `tertiary-fixed`)**: `#37007e` / `#eaddff`
- **Основной текст (`on-surface` / `on-surface-variant`)**: `#0b1c30` / `#444651`

## Типографика и символы
- **Заголовки**: `Plus Jakarta Sans` (600–700)
- **Основной текст**: `Inter` (400–600)
- **Коды, таймеры, хэши, страницы**: `JetBrains Mono` + `tabular-nums`
- **Поддержка казахского языка**: полная поддержка `Ә, Ғ, Қ, Ң, Ө, Ұ, Ү, І` в интерфейсе и встроенном шрифте `DejaVuSerif` при экспорте PDF.

## Адаптивные брейкпоинты и ориентации
- `320px` / `390px`: одноколоночная вёрстка, нижняя панель навигации без горизонтального скролла, доступность всех основных действий.
- `768×1024` (планшет портрет): документ сверху/на весь экран, выдвижная панель замечаний.
- `1024×768` (планшет альбом): документ и панель замечаний рядом в две колонки.
- `1440px` (десктоп): фиксированная левая боковая панель (`w-72`), двухстрочная шапка и двухколоночное рабочее пространство.
