# Резервное копирование и восстановление

Скрипты находятся в `scripts/`. Они выполняются на хосте с Docker и PowerShell 7 (`pwsh` на Linux, `powershell`/`pwsh` на Windows). Для восстановления нужен файл `.env` с паролем PostgreSQL и `SESSION_SECRET` исходного проекта. Если секрет сессий сменить, пользователи войдут заново.

## Копия

```powershell
pwsh -File scripts/backup.ps1 -Project normocontrolcenter
```

Скрипт останавливает приложение на время снимка, создаёт `pg_dump`, архив тома загрузок, список SHA-256 файлов и манифест с контрольными суммами и числом записей. Приложение запускается в `finally` даже при ошибке. Папка `backups/` исключена из Git и Docker-образа. Перенесите всю папку копии в защищённое хранилище отдельно от сервера: она содержит персональные данные.

## Пробное восстановление

```powershell
$env:APP_PORT='3002'
pwsh -File scripts/restore.ps1 -Backup backups/YOUR_BACKUP_FOLDER -Project nccrestorecheck
docker compose -p nccrestorecheck ps
```

Укажите свою папку копии и новое имя проекта. Скрипт запрещает восстановление в исходный проект, проверяет SHA-256 архива и дампа, требует пустую целевую БД и новый том загрузок, сверяет хеши файлов и число записей, затем запускает приложение. На целевом порту проверьте вход, скачивание ранее загруженного файла и `/api/health`.

При аварии подготовьте чистый проект Compose и скопируйте туда `.env` с действующими секретами; восстановите с новым именем проекта. Переключайте внешний домен только после проверки данных. Скрипт не перезаписывает работающие тома.

На хосте настройте регулярный запуск копирования, шифрование хранилища, срок хранения и периодическую проверку восстановления. Эти настройки зависят от политики организации и не задаются приложением автоматически.
